## 这是什么

这里收三种东西：把人扎醒的话、这句话真实的出处、以及一个今天就能做的动作。

每条五个部分：

- **刺**：一句一针见血的话（≤50 字），先把你扎醒
- **人话**：翻译成大白话，不装深
- **源**：真实出处，书、人、视频，能点开复查。**这是本库和语录合集的唯一区别，也是底线**
- **光**：一个今天就能做的最小动作。扎醒不解决事，光解决
- **注**：这句是原话、是转述、还是演绎，说实话

不用全读。这是备选单，不是任务清单，挑走一条就算数。整理这套东西的人自己也没全做到。

## 条目长什么样

> **刺**：以前你把自己当成一支股票，涨跌全靠别人报价；现在你要把自己当成一棵树——涨多高，看自己扎根多深。
>
> **人话**：别人的评价是行情，不是估值。行情天天变，估值看你脚下有多少土。
>
> **源**：「第17年秋天」《你拼命想证明自己的时候，往往不是你很强，而是你很脆弱》（抖音，2026，14 分 32 秒处）
>
> **光**：今天写下三个"我不打算再跟别人比"的具体事项。就三个，写在手机备忘录里。
>
> **注**：原话直引，个别字词为可读性微调。

## 今天读哪条

没有打卡，没有进度条，没有连续天数。点开上面任一分册，随机挑一条，读完就算数。

要一点仪式感的话：今天是几号，就读该册第几条（超过该册条数就从 1 再数）。

按需查阅也行：被热点推着走，翻 [02-taming](book/02-taming.md)；睡不着，翻 [04-anxiety](book/04-anxiety.md)；想动又动不了，翻 [05-waiting](book/05-waiting.md)；歇不下来，翻 [06-rest](book/06-rest.md)。

## 参与共建

三条铁律，缺一不收：

1. **必须有源**，说得出这句话是谁、在哪说的。查无出处的一律不收，这是本库和毒鸡汤的分界线
2. **只收短句**，50 字以内，别整段摘录别人的书稿
3. **光要今天能做**，"活在当下"不是光；"把手机充电器挪到客厅"是
