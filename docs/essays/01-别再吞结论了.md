# 别再吞结论了

> 过程轴 · 与 [01-process 分册](../../book/01-process.md) 配套阅读。这是六篇里最先要写的，因为它管的是你正在做的事。读这篇文章的时候，你是在思考，还是在吞结论？

我数过自己的收藏夹，八百多条。健身教程两百条，读书方法一百多条，剩下的散落在「以后可能用得上」的各个分类里。八百多条里，我完整做下来的不超过五个。

最扎心的地方在于，每次收藏的时候我是真的高兴。看懂一条道理的那几秒钟，人会分泌一种很具体的满足感，「我今天又变好了一点」。这种感觉是即时的，是确定的，是不需要付出任何代价的。而真改变的代价是什么？慢，枯燥，重复，失败，还有很长一段时间看不到任何结果。

于是大脑学会了走捷径，用获取知识的爽感，代替真正改变的痛苦。这在「看海」那条视频里被说得很准，你不是在改变，你只是在消费「改变自己的感觉」。

## 问题出在哪

问题不出在「学」。学本身没有错。问题出在跳过过程的速度越来越快。

「第17年秋天」有一条十二分钟的视频，全程一张插画，没有任何钩子，拿到了十几万赞。她在里面说自己读文章的时候，眼睛会自动跳过那些「废话」，直接去找加粗句和结论段。然后她停了一下，说了一句我记到现在的话：那些所谓的废话，恰恰是思考的过程。

我把这句话翻译一下。一篇文章的结论，是作者从前提一步一步走到终点的结果。你直接拿走结论，等于抄了别人的终点，却没走过那条路。下次遇到类似但不一样的问题，你还是不会走，因为你从来没练过。这就是「吞结论」。你吞下了一个结论，但没有消化它，它只是穿肠而过。

我不确定这个比例，但我怀疑大部分人收藏夹里的东西，百分之九十都处在这种「吞了没嚼」的状态。我自己也是。

## 一个容易被忽略的证据

有一个证据可以自查，你能不能把一个道理讲给一个完全没接触过的人听，让他也听懂。

讲不出来，说明你只有结论没有过程。我试过讲「复利效应」，张口就是「每天进步百分之一，一年三十七倍」。讲得很快，对方点头，然后我知道他没懂，因为我也没懂。真正的理解是我能回答他的下一个问题。为什么大多数人坚持不了？复利的前期为什么看不出变化？这些问题答案都在「过程」里，而我从来没走过那段路，所以我答不出来。

这就是为什么「知道一百种自律方法，但还是每天两点才睡」。方法和行动之间隔着一条河，收藏不等于渡河，你只是把船票越攒越多。

## 那怎么办

办法一点都不新鲜，甚至很扫兴。关掉这个页面，去重复一件你早就知道应该做、但一直没做的事。

真正扫兴的成长就长这样，没有新道理，没有顿悟时刻，就是把一个三年前就懂的东西，从「知道」挪到「做到」。心理学里管「以为懂了」的错觉有过很多研究，我不引用具体文献了，因为你自己验证比引用快：挑一条你收藏夹里最老的方法，今天做一次。做完你就知道自己之前是不是在吞结论。

慢不是停滞。慢是愿意去看事情的里面，摸每一件事的纹理。结果只是一个瞬间的标点，人生是由过程构成的。

今天，十分钟，做一件早就该做的事。不求做完，求开始嚼。
