# 不等了

> 等待轴 · 与 [05-waiting 分册](../../book/05-waiting.md) 配套阅读。这一篇聊两种「等」：一种在等条件成熟，一种在等别人先开口。它们共用同一个破法。

「小兔拜托了」有一条八分钟的视频，主题是拒绝等待。她讲了一件事，我在很多人身上见过一模一样的版本，包括我自己：有件事她等了两年，一直「没空出时间」，放到了落灰。而真正动手的那天，从决定到开始，只花了一个下午。

两年和一个下午之间的差距，不是时间，是借口。

## 条件会长出来

她的原话我很喜欢：大概是因为在心里种下了胆气，即使现在已经瘦了一点，我仍然会给自己设置这样那样的新条件，延迟开始这件事。

这句自白暴露了「等」的运作方式。等变瘦，瘦了之后会长出「等肢体更协调」；等有空，有空了会长出「等状态更好」。条件满足了，它会自动长出下一个。因为「等」的真实功能不是等待条件，是推迟可能的失败。只要还没开始，就不会输。

有一个视觉证据也来自她：扎丸子头。她原来总觉得「要有个场合再扎」，后来发现平时扎也很好看。所谓「场合」，很多时候就是等出来的借口。仪式感常常是拖延的漂亮说法。

1962 年的数学还证明过一件事，和「等」有点关系。盖尔和沙普利研究过一个匹配问题，后来被称为稳定匹配，相关工作拿了 2012 年的诺贝尔经济学奖。结论简单到不像数学：在同一份心意名单里，先开口的一方，能拿到所有稳定结局里最好的那一个。等红线，是把选择权让给先开口的人。等待不仅有心理成本，连博弈上都是亏的。

## 规划的幻觉

「等」还有一件更隐蔽的外衣，叫规划。

那位行为博弈论的教授说，规划只能用在简单系统上。车可以按图纸造，因为它是简单系统；真实世界是复杂系统，几十亿人各自的想法在里面互动，没有人能画出它的图纸。他最后给的态度很老派：尽人事，听天命。

这话听起来消极，其实是把力气用对了地方。规划「三年后必须达到什么」，是在指挥一个你指挥不了的复杂系统，越精确越容易在第一年就作废；规划「方向加下一步」，是在你唯一能控制的范围内动手。确认偏差会让我们先做决定再找理由，控制错觉会让我们觉得多用力就能掷出大点数，规划感恰恰是这两种错觉的合体。我不是说不要想未来，是想未来的正确单位是「下一步」，不是「三年后」。

## 十分钟版本

她视频的收尾是那句流传很广的话：哪有那么多万事俱备。我们最大的奢侈，从来不是等到所有条件都成熟，而是在不完美的当下，依然愿意出发。

中间还有一段我喜欢：等石膏干的那一个小时，她去楼下吃了沙拉，成品当天拿不到，就说留个悬念。等待没有办法全部取消，但可以换个身份，从「卡住的时间」变成「过程的站台」。

今天就能做的版本：把一句「等我……就……」改写成「现在就……十分钟」。等健身的，现在做十个俯卧撑；等开头的，现在写第一句。十分钟什么都证明不了，但十分钟能把「等」这个词，从今天的字典里划掉一次。
