# 焦虑坐副驾驶

> 焦虑轴 · 与 [04-anxiety 分册](../../book/04-anxiety.md) 配套阅读。这一篇不打算教你消灭焦虑，因为那做不到。它想讨论的是座位问题：焦虑应该坐在哪里。

凌晨三点睡不着的时候，你在想什么？我猜大概率是还没发生的坏事，在脑子里提前演了好几遍。明天开会会不会说错话，那条消息要不要回，三十岁之前能不能攒够钱。事情还没来，你已经替它难过过好几轮了。

「第17年秋天」管这个叫预演。她的原话是，很多焦虑不是事情已经发生，而是我们在脑子里先替它发生了一场预演。预演有个很亏的属性：它不减少真实伤害，只增加体验次数。坏结果来了，你痛一次；坏结果没来，你已经痛过三轮，最后这三轮全是白痛。

## 越不确定，越想用力

有一位研究行为博弈论的教授讲过一个骰子的例子，我认为是理解焦虑的最好入口。掷骰子想要大数，你会不自觉地用力掷；想要小点数，会轻轻丢。但骰子的点数和用力没有任何关系。这个错觉在心理学里有正式名字，控制错觉，艾伦·兰格 1975 年在《人格与社会心理学杂志》上发表过一系列实验，她发现人会把纯粹随机的结果当成自己可以影响的，哪怕只是亲手选一张彩票，都会觉得中奖率更高。

把骰子和焦虑连起来看：未来越不确定，人越会产生「我能控制」的错觉。很多规划行为，仔细拆开看，规划本身未必有用，它首先是在缓解「控制不了」的恐慌。我不是说规划没用，规划当然有用，但要分清哪一部分是在解决问题，哪一部分是在表演控制。

## 座位问题

那焦虑该怎么办？「第17年秋天」的答案是我见过最可操作的一个版本：不是把焦虑消灭，也不是隐藏，把它请到副驾驶，让它提醒你，但别让它开车。

焦虑是进化留下的警报器。完全拆掉警报器的车，开不远，该怕的东西不怕会出事。但方向盘必须在你手里。警报器和司机的区别在于，一个负责提醒，一个负责决定。

她配套给了两个小工具，我都在用。

第一个叫焦虑预算。给自己十分钟，把担心的事全部写下来，时间一到就合上本子，去做下一件小事。原理和给小孩吃糖一样，不能不给，也不能全天候给。焦虑被允许了，反而不会满地打滚。

第二个叫语言替换。把「我必须成功」换成「我今天把该做的做好」。前半句盯结果，而结果从来不由你一个人决定；后半句盯过程，过程是你真正能掌控的。这不是自我安慰，是把注意力从你管不了的骰子，挪回你管得住的手上。

## 镜子

《庄子·应帝王》里有一句，「至人之用心若镜，不将不迎，应而不藏，故能胜物而不伤」。心要像镜子：事情来了就照，走了就空，不迎接，不挽留，不私藏。她的翻译很口语：焦虑来的时候，看见它，不迎上去和它打架，也不把它藏起来骗自己。

打工会累，藏会久。只有照见，是不花力气的。

最后回到那三个问题。为了表达，还是为了讨好？为了分享，还是为了数据？她自己的答案是，想清楚这一点，不是问题消失了，是我终于记起我为什么出发。焦虑没变小，是你变大了。

今天的动作：睡前设一个十分钟闹钟，把担心的事写下来。闹钟一响就合本子，今晚的事只剩睡觉。
