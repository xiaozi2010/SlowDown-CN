# 允许摆烂

> 休息轴 · 与 [06-rest 分册](../../book/06-rest.md) 配套阅读。这一篇写给所有「休息的时候心里不舒服」的人：事情都做完了，瘫下来刷手机，还是有一种隐隐的负罪感。

先讲一个模式。周一到周五绷得很紧，计划精确到小时；周六彻底躺平，刷手机刷到恶心；周日晚上开始自责，然后立一个比上一周更狠的新计划。下一周，重复。

「江江江山」有一条表达力训练视频，讲的是钟摆效应：情绪和状态向一个方向摆得越猛，反弹越狠。考研的人前两周紧绷到极致，一旦看不到成果，几天之内直接摆烂到不想碰书；减肥的人三餐并一餐，结局往往是报复性暴食，体重不减反增。

这里要诚实说明一句：钟摆效应是个流传很广的通俗心理学术语，不是严格的实证构念，网上说它出自荣格，但这个说法只查到百科级来源，另一边明言出处不明。我保留这个名字，因为它描述的现象是真实的：极致的克制，等来的往往是报复性的放纵。摆的幅度越大，回摆越狠。紧绷一周换来周日瘫平，这怪不到你的毅力头上，是摆幅设计错了。

## 你自己抽自己

比摆幅更深一层的，是不敢停。

「第17年秋天」的描述是：心里有个声音，你不赢，就不配存在。这不是力量，是恐惧。她引用韩炳哲《倦怠社会》的说法往下挖了一层：从前是老板拿鞭子抽你赶进度，现在是你自己抽自己，还说这叫成长。凌晨两点改完方案，发一条朋友圈说热爱这份工作。功绩社会最厉害的地方，是剥削者搬进了你心里，你还替他鼓掌。

我自己对这段话的体会是，「有用」这个词很危险。机器不需要被爱，只需要被使用。一个人一旦只用「有没有产出」来衡量自己的时间，就会慢慢感受不到产出之外的任何东西，休息变成偷窃，发呆变成犯罪。

## 活着才有资格谈复利

博弈论里有一个和「停不下来」直接相关的工具，凯利公式。它最核心的推论用大白话说是这样的：在任何长期博弈里，最重要的事是活着，保证自己任何一局都不出局，因为只要出一次局，之前所有的复利都和你没关系了。那位教授的原话更狠：不管市场好坏，你一定要活下来，活下来才能享受长期主义的复利。

身体就是那个不能出局的筹码。熬垮一次，前面所有努力清零重算。

所以可持续不是懒，是数学。能坚持十年的节奏，好过能撑十天的完美计划。设计计划的时候，主动留出「允许摆烂日」，写进日历，到日子心安理得地歇。这不是计划里的漏洞，是计划本身。

## 放学以后

那位教授还有一句话，很多年轻人听完说是被说中了：过去几十年的发展造就了岗位，但没有造就职业。有前途的、值得追求的东西变少了，放学以后的时间被补习和加班占掉了。他说这不是你的错，是结构没给你留位置。

结构改不了，三十分钟可以自己抢。今天做一个很小的动作：把计划里最狠的那一项，砍掉 20%。省下来的时间不算加班，不算学习，什么用途都不安排。睡前写一句就行：今天我什么都没挣到，但我依然完整。

你输了不会变少，停下来也不会消失。慢下来的那部分时间，不是从人生里扣掉的，是人生本身。
