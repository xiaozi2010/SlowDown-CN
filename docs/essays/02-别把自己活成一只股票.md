# 别把自己活成一只股票

> 驯化轴 · 与 [02-taming 分册](../../book/02-taming.md) 配套阅读。这一篇管的是所有「别人给你报价」的时刻：排名、点赞、绩效、别人家孩子。

先讲一个我自己对号入座的瞬间。有一次我发了一条朋友圈，半个小时里给两个共同好友点了赞的人，跳过了我那条。我注意到自己在想「他为什么不给我点」，想了大概十分钟。十分钟之后我才反应过来：一条我本来只是随手分享的东西，什么时候变成了一场考试？

「第17年秋天」管这个叫微型考试。她说，你发一条朋友圈不是在分享，是在等审判，考官是你想象中的所有人。她的原话还有一层更狠的：现代社会把「我是谁」，悄悄改成了「我排第几」。

## 股票和树的区别

这一篇的核心就是一个比喻，出自她同一条视频的结尾。

以前你把自己当成一支股票，涨跌全靠别人报价。老板的表情是行情，同事的成就是行情，朋友圈的点赞数是行情，你活得像一个盯盘的人，每天开市闭市都紧张。现在换成把自己当成一棵树。树的成长看什么？看脚下有多少土，扎了多少根。别人比你高，你不用慌，因为你们本来就不是同一种行情，你有你的土，你有你的季节。

这个比喻好用在于它能拆穿很多东西。比如胜负心。追求卓越和胜负心的区别，她自己举过一个例子：跑步比昨天多跑一公里，很开心，这是追求卓越，尺子在自己身上；跑步只为了朋友圈步数第一，排第二就难受，这是胜负心，尺子在别人身上。股票逻辑的人永远是后者，因为他没有自己的尺子，他的价值要靠别人的报价来确认。

## 这个结构是怎么搭起来的

往下挖一层，这不是性格问题，是结构问题。

「郝奕会客厅」请过一位研究行为博弈论的教授，他讲补习班那一段，我认为是对内卷最准确的一段描述。我不去，别人家的孩子去了，差距就拉开了，所以所有人都去了。最后所有人多花了钱，排名一张没变。他补了一句更狠的：内卷不是家长不理性，恰恰是所有人太理性的结果。

每个人的最优决策，加起来是一场集体内耗。这就是博弈论里的囚徒困境。看清楚这个结构有个好处：你可以停止责怪自己「不够洒脱」。你不是心态差，你是被困在一个规则坏掉的局里。而看清规则，是从局里出来的第一步。

博弈论里还有一对概念，有限游戏和无限游戏，出自詹姆斯·卡斯的《有限与无限的游戏》，1986 年的书。有限游戏每一局都要赢，赢完游戏就结束；无限游戏这一局可以输，但要保证游戏还能继续玩下去。那位教授举的是李嘉诚的例子：每单都让合作伙伴赚大头，看起来每局都输一点，但所有人都愿意跟他玩下一局。所有便宜都赚、所有亏都不吃的人，很快就没有人跟他玩了。

## 换尺子

具体怎么做，她给过一组「五句替换」，我挑两句最好用的。

第一句，把「我排第几」换成「我对谁负责」。前者是行情，后者是根。第二句，在卷一件事情之前，先写下「我为什么必须赢它」。写得出来，就继续，那是你的事；写不出来，就可以放手了，那大概率是别人塞给你的行情。

你输了不会变少，停下来也不会消失。需要你一直盯盘才成立的价值，本来就不叫价值，叫持仓焦虑。

今天先做一件事就行：把手机里的步数排行、阅读排行、任何一个你最近在意的排行，关掉一个。
