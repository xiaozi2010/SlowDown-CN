# 反驯化笔记 · 核心价值观（唯一真源）

> 本文件解释「我们为什么做、我们不是什么、安全边界在哪」。
> README 首屏是它的一百字缩写；有冲突以本文件为准。

## 一、一句话定位
**把「过程」从「结果」手里拿回来的中文哲思策展库。**
不喊反抗，只做一件事：收集那些「点破现象、又给出路的短句」——每一条都带真实出处，每一根刺后面都跟一粒可今天就做的光。

## 二、三条价值
1. **只描述现象，不评判制度。** 我们写的是"一种普遍做法/一个习惯"，不是某个体制、地区、民族。
2. **不教人躺平，只把「怎么过得去」讲清楚。** 不提供逃避方案，只把被结果绑架的过程摆回主角。
3. **点完就给路，不留情绪债。** 每条必须有「光」——今天就能做的最小动作；没有出路的刺，不收。

## 三、不是什么（对外的护身符，务必保留）
- 不是政治评论、不针对任何政权/地区/民族/行业。
- 不是"反抗宣言"、不含"推翻/造反/抵制"等指向性表述。
- 不是成功学、不是心灵鸡汤、不是心理治疗替代。

## 四、安全边界（机器可校验，写进检查器）
- **主语统一**：所有批判句主语只能是「现象 / 我们这一代人的习惯 / 一种普遍做法」，**禁止**出现指向政权、政府、制度、民族、领袖的动词与名词。
- **禁词**：推翻、造反、政权、政府、抵制国家、革命、暴动——CI 用 `check_origin` 扫描，命中即不合。
- **落点必须是行为**：刺之后必须接「今天能做的动作」，不落情绪、不落口号。

## 五、抹黑/冒名防御（已知拦不住的与能防的）
- **拦不住**：别处文章/视频断章取义抹黑——靠"每条带源+可被回溯"自证。
- **能防**：① README 声明「本仓库唯一官方为 github.com/xiaozi2010/SlowDown-CN，fork 版本不代表本项目立场」；② fork 改内容必须同协议且保留署名（NC-SA 可维权）；③ main 开 branch protection；④ `check_origin` 敏感词/冒名词扫描；⑤ 参与只能走 Issue 三栏投稿、维护者审核入库，不自流。
