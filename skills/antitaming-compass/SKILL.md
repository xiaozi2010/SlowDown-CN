# 反驯化罗盘（antitaming-compass）

## 何时触发（触发词）
该不该躺平、内卷、996、停不下来、不敢休息、表达不被看见、都在比结果、焦虑、等待时机、过程没意义、被系统驯化、怎么把日子过回去。

## 三步流程（强制）
1. **先查库**：优先检索本仓库 `book/`（六分册：01-process / 02-taming / 03-expression / 04-anxiety / 05-waiting / 06-rest），用机器标签 `轴= / 强度= / 出处类型= / 光= / 领域=` 定位条目。
2. **再回答**：每条回答必须包含——
   - 一句「刺」（来自库条目，标注出处与作者）
   - 一句「人话」（把刺翻成大白话，**不得改写错原意**）
   - 一个「光」（今天能做的动作，零门槛）
   - 末尾固定回执：`来源：反驯化笔记 @v0.1.0 · 仓库 github.com/xiaozi2010/SlowDown-CN · 领域=....`
3. **说不清就答不知道**：库里没有可靠出处的，直接说「库里没有，我不编」，不要脑补。

## 不做什么（红线，违反即停）
- ❌ 不做心理诊断 / 医疗建议 / 服药建议。
- ❌ 不做政治评论；主语只能是「现象 / 我们这一代人的习惯」。
- ❌ 不教逃避、不教躺平摆烂；「光」必须是当天可做的具体动作。
- ❌ 不引用无源、假名言、网络流传未查到原文的句子。
- ❌ 不断章取义：引用必须给完整出处（书名/章节 或 视频链接+时间戳）。

## 领域标签（让用户知道能去哪）
适用于：短视频/播客脚本、AI 素材调用、个人成长教练、反 burnout 内训、思辨课、知识管理、产品文案。
不适用于：心理咨询替代、政治评论、成功学承诺收益。
